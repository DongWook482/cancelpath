Privacy Policy

Last updated: 24 November 2026.

CancelPath is a static informational website. We want this policy to stay accurate, so it only describes practices that are in use today.

Information we collect

This site does not ask you to create an account, submit a form, or pay for anything. We do not run advertising or an affiliate program at this time, and we do not operate a first-party comment system.

Google Analytics

CancelPath uses Google Analytics 4 (GA4) to understand how the public site is used (for example, how many people visit, which pages are viewed, and from which general regions or devices). The measurement tag runs on every generated page. Google may collect device and usage data such as IP address, browser type, referring URL, and page path, and may set or read cookies or similar storage in your browser.

This processing is handled by Google under the Google Privacy Policy. Google also explains how it uses data from sites and apps that use its services at policies.google.com/technologies/partner-sites.

Hosting logs

The site is hosted on GitHub Pages. GitHub may process standard server or CDN request data (such as IP address, user agent, and requested URL) according to the GitHub Privacy Statement. CancelPath does not receive a copy of those logs.

Cookies and advertising

CancelPath does not run Google AdSense or any other ad or affiliate network today. Google Analytics may set or read cookies (or similar storage) for measurement only. If advertising or affiliate links are added later, this Privacy Policy will be updated before those features go live, and any required consent or disclosure will be added at the same time.

External links

Guides link to official company portals, support pages, and public discussion threads. Those third-party sites have their own privacy practices, which we do not control.

Changes

Material changes to this policy will be posted on this page with an updated date. Questions about this policy can be raised on the project's public GitHub repository.
